# Control4 架构要点（公开层）

fetched_on: 2026-10-21

## 控制器分层（公开营销 / 数据表）

- CORE 系列为现行 OS 3 控制器家族：CORE 1 / 3 / 5（及公开可见的 CORE 相关文档）。
- 控制通道公开提及：IP、IR、串口、Zigbee；CORE 5 数据表另列 Z-Wave 天线。
- 娱乐：Ryff 高分辨率音频服务；HDMI 上屏 UI；多区音频随型号变化。
- 远程与网络：控制器内置 **OvrC Pro**；业主 App 与远程能力与订阅绑定（Connect / 文中 4Sight）。
- 对讲：内置 communication server，对接 T4 / Chime 门铃等（数据表表述）。

## 与第三方

公开页强调庞大驱动库与网络设备经 OvrC 远程管理；完整驱动目录与 Composer 工程结构未在公开层展开。
