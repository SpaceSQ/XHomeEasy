0 文档信息

术语：CEDIA（Custom Electronic Design & Installation Association）；RFQ（Request for Quote）；Dealer of Record / Smart Home Pro（Control4 集成商备案）；OvrC（Snap One/Control4 远程管理平台）；Composer Pro（Control4 经销商编程工具）；Crestron Home OS / Configure Pro；Savant Host / Essentials；Lutron HomeWorks / Clear Connect；结构化布线（structured wiring）；低电压（low-voltage）vs 市电（line-voltage）。
1 执行摘要
一句话定位：让一位不懂专业集成的北美别墅/大宅业主（或建筑师/室内设计师），在一次会话内弄清“我家适不适合有线全屋集成、四巨头怎么选、预算里安装费大概占多少、该问集成商什么”，带着一份标准化 RFQ 去找 3 家本地授权/持证集成商，并在报价对比、合同、项目文件移交、施工与运维各环节都有中立的“懂行的朋友”陪着。产品是项目制决策平台加双边市场，与 Matter 版的 C 端零售订阅工具根本不同，与 KNX 版的欧洲 Partner 体系流程同构但生态封闭性更强。
1.1 核实结论要点（详见第 2 章与《市场核实表.md》）
专业集成渠道规模：CEDIA 2026 研究估美国住宅科技集成行业 338 亿美元（自下而上，287 名从业者访谈）。这是专业安装口径，不是零售 Matter 口径（X01）。
品牌地位：全屋控制 Top-3 提及率 Control4 63%、Crestron 43%、Savant 33%、Josh.ai 32%；照明/遮阳 Lutron 分别 76%/77%（X02）。
Control4 官网：50 万+ 家庭、近 6,000 授权集成商、25,000+ 第三方互通；2024-06-14 Resideo 以约 14 亿美元完成对 Snap One 收购并并入 ADI（X03、X04）。
“经销商锁定”不可一刀切：Control4 在 OvrC 移交前提下支持客户自助换集成商；Savant/Crestron 编程与订阅更依赖经销商——合同须按品牌分列移交条款（X05）。
安装费占比只有服务商/媒体口径：编程常见约 15–25% 项目成本；人工+编程+机柜/收边常见 30–55% 量级——必须标不确定性（X06）。
竞争空白：CEDIA/厂商目录与通用找工匠平台已有；中立的“适配→RFQ→报价对比→移交→陪伴”全流程 App 截至 2026-10-21 公开检索未见成熟品类（X13）。
1.2 核心主张
合围战略第四极：用户已有①北美苹果智能家居 APP（自有）、②北美 Matter 购买决策、③欧美 KNX 购买决策；本产品切北美难度最高、历史最久的有线/专业集成市场，与前三篇形成“零售无线 ↔ 欧洲总线开放标准 ↔ 北美封闭专业集成 ↔ 苹果生态”合围。
护城河是证据分级的“平台×集成商×合同移交”知识图谱：授权等级、CEDIA/HTA 认证、品牌徽章、远程订阅政策、项目文件/源码移交差异、区域密度。每条事实标 E1–E4、来源与核实日期。
最大单点价值：预算透明（设备 vs 人工 vs 编程 vs 布线/机柜）+ 标准化 RFQ + 结构化报价对比 + 分品牌交付资产清单。
商业模式：项目制高客单低频。B 端（集成商订阅/合格线索）+ 业主一次性深度方案报告 + 建筑师协作席位 + 可选厂商目录合作；不做以 C 端月订阅为主。收入测算全部标为模型。
安全边界：只做认知、决策、RFQ、比较、合同要点、找持证/授权集成商与进度陪伴；不提供市电或机柜 DIY 接线步骤。
1.3 MVP 范围（建议 M0–M4，约 20–22 周；首发美国 2–3 个都市圈 + 英语）
Web 优先（SEO、建筑师协作）+ iOS/Android 轻客户端：有线 vs Matter/Apple Home 适配问诊 → 房间功能卡片与 Good/Better/Best → 预算区间（分项+来源+不确定性）→ 四巨头对照表（证据分级）→ RFQ PDF/结构化链接 → 集成商目录（厂商授权徽章 + CEDIA/HTA + 认领）→ 最多 3 家报价结构化对比 → 合同与分品牌移交清单。B 端 MVP：认领、资料、接收 RFQ、结构化报价。施工进度与运维模块可在 M3–M4 以清单+提醒形态上线。

3.2 项目制购买旅程与痛点
认知：业主从设计师/邻居/CEDIA Expo/品牌秀场听说“智能家居”，但分不清 Matter 零售与专业集成。
咨询：联系 1–2 家本地集成商，听方案——常被引导至该商最熟悉的单一品牌。
设计与报价：格式不一，设备/人工/编程/机柜混写，无法横向比。
签约与施工：与水电、木作抢工期；低电压与市电职责不清易扯皮。
编程调试与验收：界面是否好用极大依赖集成商水平；项目文件/账号移交常未写清。
运维扩展：订阅（Connect/Essentials 等）、远程监控、加设备都依赖原商或换商流程。
对照 Matter：零售是“下单→自己配对”；本市场是“关系→方案→施工→长期服务”。
3.3 新建 vs 改造
新建/大翻新：可做结构化布线、独立机柜/弱电间、预留影音与遮阳管线——APP 最重要提醒是“干墙前的布线窗口”。
改造：更多依赖 Lutron Clear Connect、Control4 Zigbee、局部拉线；APP 按房间标记“可布线 / 倾向无线 / 需现场评估”，不下替结论。
CEDIA 2026：住房活动走软、材料与关税承压，但 78% 企业仍预期营收增长——改造与存量运维对平台同样重要。
3.4 预算与安装费心智（只写有来源的区间）
以下均为服务商/媒体口径或协会品类结构，不是全国官方均价。APP 展示时必须附来源标签与“以现场报价为准”。
全屋高端：$75k–$250k 常见；庄园级可超 $500k（homeautomation.us.com，2026-10-21 访问）。
粗分项（同文，$150k 示例）：布线基础设施 15–20%；照明 20–25%；影音 20–30%；控制平台硬件+编程 15–20%；安防/网络/暖通/遮阳 10–20%。
编程：约 15–25%（Crestron Home 集成商博客）；工时费率举例 $100–250/小时。
人工+编程+机柜/收边：有来源称占总票价约 30–55%（reviewbook，方法不透明，量级参考）。
设备侧：无统一 MSRP 货架；经销商进货经 ADI/Snap One/Wave/厂商渠道，对业主报价含服务溢价。
4 四巨头与竞品分析
4.1 四巨头对照（只写核实过的能力与结构差异）

证据说明：心智份额来自 CEDIA 2026；Control4 规模来自官网；能力描述来自各官方产品/服务页与文档。未核实的“谁更好用”不做结论。RTI、ELAN、UBI、B&O 等在 APP 中作“周边平台”卡片，深度低于四巨头。
4.2 Josh.ai、Resideo/Snap One 之后、Amazon/Google
Josh.ai：CEDIA 2026 全屋控制提及 32%；官方与 Crestron/Control4 等有集成页；常作高端本地语音层叠加，而非简单第五替代巨头（X09）。
Resideo←Snap One：分销与专有品牌（Control4、OvrC、部分 AV/网络品牌）能力并入 ADI，集成商采购路径变化——APP 的 B 端价值包含“供货与支持网络”信息，但不做分销商排名买卖。
Amazon/Google：未证实替代专业有线；更常见为语音前端。风险是业主误以为“买 Echo 等于全屋集成”——适配模块必须解释清楚。
4.3 购买指南 / 找集成商竞品

竞争空白总结：没有产品把“有线 vs 无线/Matter/Apple Home 适配 → 四巨头(+Lutron 底座)中立对照 → 安装费透明 → RFQ → 多家报价结构化对比 → 分品牌移交与验收 → 施工/运维陪伴”串起来。
5 分销、安装生态与价格构成
5.1 分销与工程商特点
厂商授权体系：各品牌独立认证与等级（如 Control4 Diamond/Platinum/Gold/Authorized、Assist、Certified Showroom）。
协会：CEDIA 会员 + 个人认证 CIT / IST / RNS / ESC-D（CIT/IST 经 ANAB ISO 17024）。
分销：ADI Global（含原 Snap One）、Wave 等向集成商供货；业主一般不直接向分销下单买全屋。
区域密度：都市圈与阳光带高端住宅区集成商密度更高（CEDIA 调研受访者南区 43% 等，反映样本而非精确供给地图）——冷启动按都市圈密度选点。
获客：转介与 GC/设计师/建筑师渠道主导（X14），APP 必须做 B2B2C 与设计协作，而不是只做 C 端广告。
5.2 安装技术体系与标准（安全边界内）
阶段：设计 → 粗装布线（pre-wire）→ 设备安装/机柜 → 编程调试 → 业主培训 → 维保。
低电压 vs 市电：灯光负载、配电与高压作业属持证电工范围；集成商多负责低电压、网络、控制与编程。州执照差异大（NSCA、得州豁免例）——APP 只提示“查本地执照”，不替代合规判断。
结构化布线与机柜：遵循适用 ANSI/TIA 实践与 CEDIA 最佳实践；详细标准编号在工程化阶段补进知识库（X16）。
APP 禁止：任何逐步市电接线、配电箱改接、破解经销商软件的内容。
5.3 运维服务平台
Control4：OvrC + Connect + Assist；换商流程见官方帮助中心。
Savant：Home Manager / Essentials（经销商媒介）。
Crestron：myCrestron 住宅监控等；XiO Cloud 主要不是住宅业主订阅叙事。
APP 角色：解释“本地集成商服务计划 vs 厂商 Assist 类 vs 平台云订阅”的差异清单，协助业主对比续费项——不代理厂商收费。

6 产品定位与设计原则
中立：排序看匹配度与证据，不看佣金；付费/赞助位标明 Sponsored，并公开主要排序参数（FTC 精神 + 平台透明度最佳实践）。
证据分级 E1–E4：E1 协会/法规/官方流程；E2 厂商官方；E3 平台核验（认领证照、项目资料）；E4 未核验公开信息。冲突时展示冲突。
可解释：每个推荐附“为什么”、证据等级、核实日期。
AI 透明：首次对话声明 AI；生成内容标明来源片段。
安全边界：见附录 B。
不锁定业主：默认推动项目文件/账号/配置备份进入合同；平台数据可导出。
合围一致语言：与 Matter/KNX/苹果三篇共享“证据徽章、Good/Better/Best、RFQ、安全边界”交互语言，降低品牌教育成本。
7 功能模块设计
本章为完整功能规格，供研发拆解用户故事与验收标准。优先级见 7.13。每个模块含：用户故事、关键页面、交互特点、数据来源。
M1 有线集成适配判断（vs Matter / Apple Home / 混合）
用户故事
作为业主，我想知道我家更适合专业有线集成、零售 Matter，还是混合，以免买错路径。
作为设计师，我想要一页中立说明发给业主。
关键页面
问诊：住宅类型/面积量级、新建或改造、是否有弱电间、预算意向档、是否已有 Apple Home/Matter/某品牌遗留系统、是否需要影院/多房音频/电动遮阳/泳池等。
结果页：三条路径评分卡（有线专业 / Matter 零售 / 混合）+ 证据说明 + “不适合 DIY 的红线”。
交互特点
对话式 + 房间/场景芯片；结果用交通灯+文字，不只靠颜色。
明确写出“评分是启发式模型，不是厂商认证”。
数据来源
CEDIA 品类结构、Parks/Berg 背景渗透（标明口径）、Matter 篇已核实的平台能力矩阵（内部复用）、本表 X10/X17/X18。
M2 房屋与需求问诊（房间卡片）
用户故事
作为非专业业主，我想按房间勾选灯光/遮阳/影音/气候/安防/泳池，而不是填技术表单。
关键页面
户型草图或房间列表生成器；每房间功能开关；整屋级需求（门禁、景观、机柜位置假设）。
导出“需求摘要”供设计师批注。
交互特点
低门槛：大卡片、图标、可选拍照备注（仅本地或经同意上传）。
建筑师只读/批注权限。
数据来源
用户输入；可选与公开户型模板库（自建，非爬取私人图纸）。
M3 四巨头选型对照与 Good / Better / Best 方案
用户故事
作为业主，想在 C4/Crestron/Savant + Lutron 照明底座之间看到中立对照，而不是只听一家集成商。
关键页面
对照表（能力、渠道、订阅、移交、适合复杂度）每格挂证据徽章。
三档方案：Good（以照明+网络+基础控制为主）、Better（加分布式音频与安防整合）、Best（影院/多区视频/能源/语音层等）——均为示意包，非报价。
交互特点
预算滑杆联动档位；滑动时分项区间刷新。
突出“Lutron 照明底座 + 控制层品牌”的常见工程组合。
数据来源
X02–X08、X11、X22；厂商官方页；禁止无来源的“评测打分”。
M4 预算区间与安装费透明化
用户故事
作为业主，想看清设备/人工/编程/布线/机柜/订阅大概占比，避免只被报一个总价。
关键页面
分项堆叠条 + 不确定性带宽；来源抽屉（媒体/协会/“待现场”）。
“该问集成商的 10 个价格问题”清单（含编程小时数、变更单价、差旅、订阅是否强制）。
交互特点
默认显示区间而非单点；下载 PDF 附免责声明。
数据来源
X06、X07；用户不可把模型当作报价。
M5 标准化 RFQ 生成
用户故事
作为业主，想一键生成可发给多家集成商的需求书，减少信息不对称。
关键页面
RFQ 含：项目地址级（可模糊到邮编+城市）、范围、房间表、偏好平台（可多选或“请建议”）、预算档、工期、现场访问窗口、必须回答的移交条款、保险与执照要求。
导出 PDF + 结构化链接（集成商工作台可一键导入）。
交互特点
可隐藏个人电话，先经平台转发（反垃圾）。
数据来源
用户输入；模板法务审阅（假设需外聘）。
M6 集成商匹配与画像
用户故事
作为业主，想找本地授权/持证集成商，并看可引用的事实而非营销话术。
关键页面
地图/列表：距离、品牌授权徽章、CEDIA/HTA、Assist 等（E1/E2）、认领完善度（E3）、服务半径。
画像卡：只列可引用事实+来源日期；“认领更正”入口；无主观星级算法黑箱。
交互特点

10 项目策略与市场进入（合围定位）
10.1 合围战略中的位置
SCR-LAB 智能家居产品线形成四象限合围（战略表述，非市场规模命题）：
象限 A — 北美苹果智能家居（用户自有）：深挖 Apple Home 用户体验与设备选择。
象限 B — 北美 Matter 购买决策（已交付设计书）：零售/DIY、兼容性红绿灯、Thread 规划。
象限 C — 欧美 KNX 购买决策（已交付设计书）：开放总线标准、Partner 等级、ETS 移交。
象限 D — 本产品 X Home Easy：北美封闭/半封闭专业集成，项目制+经销商，安装费与移交是核心痛点。
交叉导流（假设）：Matter 用户若预算与户型触发“专业集成更合适”红线，则深链至 X Home Easy 适配；KNX 国际业主移居北美时导至本产品；苹果生态用户需要 Lutron/Control4 底层时导至本产品的“混合架构”说明。各 APP 保持品牌中立，导流位披露关系。
10.2 市场进入顺序（建议）
Y1：美国 2–3 个都市圈英语 MVP（Web+轻 App），验证 RFQ→报价→选商转化。
Y1.5：加拿大英语城市（注意省执照差异），复用内容。
Y2：扩展都市圈；加强设计师/建造商包；评估与 CEDIA 教育内容合作。
不作为重点：试图全国铺开但每城不足 3 家响应的“空目录”；不做中国市场。
10.3 与 CEDIA / 厂商关系策略
CEDIA：争取内容合作、教育引用、Expo 展位或会员沟通；不宣称官方背书除非签署；目录数据以公开页+认领为主，不侵犯协会 ToS。
厂商（Control4/Resideo-ADI、Crestron、Savant、Lutron）：目录与培训内容合作、共同办设计师午宴；明确合同：合作不影响 C 端排序；拒绝“只推单一品牌”的排他条款。
分销（ADI、Wave 等）：可探索面向集成商的工具联名，不面向业主售货。
风险：厂商自建业主体验中心与 Locator 更强——我们的差异化永远是中立对照与合同资产，而非另一份经销商黄页。
10.4 B2B2C 动力设计
业主要中立与省心；集成商要高质量意向（预算与范围清晰的 RFQ）；设计师要可复用的说明材料。
平台规则：禁止出售隐私；线索质量差可退；刷单评价清零。
与 Matter 订阅产品共享设计系统与账号（假设），但计费账户分离。
10.5 不做什么（战略舍弃）
不做安装劳务派遣或总包。
不做厂商编程软件的非授权替代品。
不做“保证最低价”的交易平台（破坏集成商关系且合规风险高）。
不以 C 端月订阅为主要收入叙事。
